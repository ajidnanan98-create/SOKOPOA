# SOKOPOA — Development milestone 1

SOKOPOA is being built as one Flutter/Dart codebase for Windows and Android, with local
SQLite storage, a separate FastAPI backend and central PostgreSQL database.

**Design:** approved Light Professional theme — white/light-grey workspaces, navy navigation
and headings, green success, amber warnings and red critical states.

Read `docs/DEVELOPMENT_STATUS.md` before using this package. This is not yet a production
accounting system. Follow `docs/RUN_NEXT.md` to open the Flutter project.
